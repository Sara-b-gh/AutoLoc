## Acteurs et cas d'utilisation

Les acteurs identifiés pour le système AutoLoc sont :

  Client : consulter les véhicules disponibles, effectuer une réservation et consulter ses réservations.
  Agent d'agence : gérer les clients, les véhicules et les réservations.
  Responsable d'agence : superviser l'agence, les employés et les activités de l'agence.
  Administrateur : gérer les utilisateurs et administrer le système.

Cette liste représente une première identification des acteurs et des cas d'utilisation d'AutoLoc. Elle pourra être complétée et précisée dans les prochaines séances.
